# Lenguaje C vs Lenguaje C++

 En este texto vamos a hacer un análisis comparativo del tipo String en Lenguajes de Programación. En este caso estaremos comparando los lenguajes c y c++.

 El lenguaje c es un lenguaje de programación de propósito general, de nivel relativamente bajo, diseñado para obtener un alto control sobre el hardware y la memoria. Se caracteriza por su eficiencia y cercanía al funcionamiento de la máquina, lo que lo convierte en un lenguaje ampliamente utilizado en sistemas operativos y software de bajo nivel. Sin embargo, esta flexibilidad implica que el programador deba realizar manualmente ciertos aspectos, como la memoria dinámica y la manipulación de estructuras como las cadenas de caracteres. Esto aumenta la complejidad del lenguaje y la posibilidad de errores.

 Por otro lado el lenguaje c++ surge como una extensión de c, incorporando características de programación orientada a objetos, además de algunas mejoras en las abstracciones y seguridad. Permite tanto la programación a bajo nivel, similar a c, como el uso de abstracciones de alto nivel. Incorpora tipos como std::string, que analizaremos más adelante, lo que simplifica la programación, reduce errores y mejora la productividad del desarrollador.
 
 Como se puede observar, existen diversas diferencias entre c y c++ con respecto al manejo de Strings, tanto en su diseño como nivel de abstracción. En el lenguaje C, el string no es un tipo de dato nativo, sino que es un tipo derivado que se construye a través de un arreglo de caracteres que termina con ‘\0’, lo que implica un manejo manual por parte del programador. En cambio en c++ existe la posibilidad de utilizar std::string, una clase definida en la biblioteca estándar, diferenciándose de los tipos primitivos que están integrados en el compilador como Int, Float, Double, etc. En C el tipo string no forma parte de él directamente, pero existe la biblioteca <string.h> la cual tiene funciones para el manejo de arreglos de tipo char, por otro lado en c++ existe la biblioteca <string> la cual establece la clase string mencionada anteriormente, junto con funciones para su uso.

 Ambos lenguajes comparten el uso del alfabeto inglés estándar, el cual puede ser contenido por el tipo string, este se basa en el conjunto de caracteres ASCII, que incluye letras mayúsculas (A-Z), letras minúsculas (a-z), dígitos decimales (0-9), caracteres especiales (+, -, *, /, {}, []) y espacios en blanco. La diferencia entre ambos radica en que c++ tiene mejor soporte nativo para alfabetos extendidos tal como Unicode con el uso de diferentes clases tales como char16_t, char32_t, etc.

 A su vez, en c la asignación de memoria es responsabilidad del programador. Puede ser estática (en el stack) por ejemplo al declarar “char nombre[20]”, se reserva un espacio de memoria de tamaño fijo o dinámica (en el heap) haciendo uso de “malloc()”, con la responsabilidad de hacer su respectivo “free()”, teniendo este riesgo de overflow en el buffer si los datos exceden el tamaño reservado. En contraste, en c++ el tipo (std::string) es una clase que gestiona la memoria de forma automática y dinámica, esta reserva, expande y libera la memoria en el heap según sea necesario, además la memoria se libera sola al salir de su ámbito (scope) a diferencia de c en el cual es necesario realizar un “free()” manual.

 Las cadenas de caracteres en c son mutables, ya que se manipulan directamente en memoria a través de punteros o arreglos. En c++, (std::string) también es mutable, pero ofrece métodos controlados para su modificación, evitando el acceso directo a la memoria y mejorando la seguridad del programa. 

 En cuanto a si los strings en c son de first class citizen, estos no cumplen completamente con esta característica, ya que no son un tipo de dato abstracto del lenguaje sino estructuras basadas en memoria. En cambio, en c++ el tipo std::string sí puede considerarse un first class citizen, ya que puede ser asignado a variables, pasado como parámetro y retornado desde funciones como cualquier otro objeto del lenguaje. 

 Además, en c las cadenas de caracteres se pasan a las funciones mediante punteros (char* o const char*), dirección de memoria, lo que implica que se trabaja directamente con ella. Esto permite eficiencia, pero requiere cuidado, ya que cualquier modificación afecta directamente al bloque de memoria original. En c++, cuando se utiliza std::string, los strings pueden pasarse por valor o por referencia (const std::string&), lo que permite mayor seguridad y eficiencia, evitando copias innecesarias cuando se usan referencias constantes. 
 
 Por otra parte en el caso de C, debido a que no se puede retornar arreglos de forma directa, las funciones suelen devolver un puntero “char*”. Si la función modifica un arreglo recibido como argumento, se podría decir que se comporta como un pasaje por referencia, por estas razones para devolver un string nuevo, se requiere el uso de memoria dinámica, para crearlo. Por otro lado, en c++, una función puede devolver una variable de tipo std::string por valor, gracias a la clase la cual se encarga de que el contenido sea gestionado de forma correcta y automática. Asimismo si el string se pasó por referencia y fue modificado internamente, la función puede elegir por no retornar el valor (void) o retornar un valor distinto (booleano), para confirmar que la operación se hizo, esto debido a que la variable original ya refleja los cambios realizados.

 En cuanto al nivel de soporte para c, con respecto a Unicode/UTF-8 es mínimo o manual, esto debido a que el tipo char es de 1 byte, lo cual encaja bien con ASCII, a diferencia de por ejemplo UTF-8 donde el programador tiene que manejar manualmente los caracteres de múltiples bytes, lo que complica operaciones simples como contar caracteres reales. En cambio en c++ el soporte es nativo, es decir viene integrado con el compilador y la biblioteca estándar, así como más 

robusto por ser confiable, completo y tener un buen manejo de casos difíciles, ya que tipos como std::string, que se suelen usar para UTF-8, así como tipos específicos como (std::u8string), (std::u16string), (std::u32string), fueron hechos específicamente para manejar diferentes codificaciones de Unicode de forma estándar.
